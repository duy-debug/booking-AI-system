# Massage / Wellness Design Direction

## Goal
Create a calm, modern wellness experience.

Prioritize:
- clarity;
- strong imagery;
- readable typography;
- generous spacing;
- simple interaction;
- visual consistency.

## Visual hierarchy
Prefer:

```text
strong headline
short explanation
clear action
supporting visual
```

Hero and service discovery should receive the strongest emphasis.

## Layout
Prefer:
- large content blocks;
- editorial two-column compositions where appropriate;
- controlled whitespace;
- limited borders;
- limited card nesting.

Avoid putting every piece of content inside a card.

## Color
Respect the existing brand/design system first.
When none exists, natural wellness tones are suitable:
- warm neutrals;
- muted greens;
- soft earth tones;
- restrained dark text.

Treat these as guidance, not fixed requirements.
Avoid excessive gradients, neon, glow and saturation.

## Typography
Keep body text highly readable.
Use clear hierarchy between eyebrow, heading, body, CTA and metadata such as duration/price.
Avoid overly decorative fonts for long-form text.

## Imagery
Prefer real service/environment imagery where available:
- treatment environment;
- massage services;
- spa details;
- oils/natural materials;
- calm interior spaces.

Use Next.js `Image` when consistent with the project.
Preserve aspect ratio and avoid oversized assets.

## Motion
Animation is optional.
If used, keep it subtle: fade, short translate, hover transition.
Do not require animation for understanding or navigation.

## Responsive
Desktop may use split layouts.
Mobile should collapse naturally to one column.
The chatbot must not cover important actions or reading content.

## Restraint
Use visual surfaces only when they provide meaningful grouping.
Avoid unnecessary nested wrappers or cards.
